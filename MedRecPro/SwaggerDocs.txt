REST API for FDA Structured Product Labeling (SPL) data per the SPL Implementation
Guide (December 2023) — https://www.fda.gov/media/84201/download?attachment.
Environment: SQL Server {environment} ({serverName}).

Expand a section below for orientation. Full endpoint, parameter, and response
documentation lives in the collapsible operation groups further down.

## 🚀 Getting Started
- Use the Auth group for Google or Microsoft sign-in, or the Authorize button for Basic authentication in Swagger UI.
- Operation groups are collapsible families — Label, Settings, Users — plus standalone groups: AdverseEvent, Ai, Auth, and OrangeBook.
- Internal numeric database keys exposed at the API boundary use encrypted string IDs; public GUIDs, operation IDs, and domain codes keep their documented formats.

## 🗺️ API Surface Map
| Group | Covers |
|---|---|
| AdverseEvent | Adverse-event dashboards: product selection, visualizations, reverse lookup, interchange comparison, and favorites. |
| Ai | AI context, interpretation, synthesis, chat and conversation management, and retry. |
| Auth | External OAuth sign-in, session management, and access control. |
| Label (12 groups) | SPL documents, sections, products, ingredients, classification, imports, comparisons, Markdown, and search. |
| OrangeBook | Orange Book patent expirations for NDA products cross-referenced to SPL labels. |
| Settings (4 groups) | Application information, managed cache, diagnostics, and administrative log queries. |
| Users (6 groups) | Authentication, directory, activity, profile, MCP integration, and account administration. |
| MedRecPro (Release only) | Application status and API entry-point information. |

## 🔑 Conventions
- Internal numeric keys use encrypted string IDs; timestamps are UTC where documented.
- Paginated endpoints document `pageNumber` and `pageSize` or their axis-specific variants.
- SPL import and comparison queue operations return `202 Accepted` with operation tracking; use the matching progress operation.

## ⚡ Operational Notes
- Swagger document caching and managed data caching are separate concerns.
- Use the Settings Cache group when a fresh managed-cache read is required.
